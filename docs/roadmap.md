# 路线图

## M0：保全与硬件验证

完成标准：

- 保存第二台设备的完整原始 Flash 与硬件身份摘要。
- USB Serial/JTAG 烧录和恢复流程可重复。
- 屏幕、背光、LED、按键、ES8311、麦克风和扬声器分别通过自检。
- 建立引脚与电平的实机测试记录。

## M1：离线身体

完成标准：

- 自研 ESP-IDF 固件可以稳定启动。
- 圆屏显示真实状态，LED 与状态一致。
- 24 kHz 音频持续采集并进入 PSRAM 环形缓冲。
- 本地 VAD、按键会话和软件静音可用。
- 播放测试音频无明显爆音，异常重启可诊断。

## M2：安全联网

完成标准：

- 完成本地配网、设备绑定、TLS 和可撤销设备凭证。
- 支持断线重连、心跳、时间同步和协议版本协商。
- 待机状态不上传原始音频，并能通过测试验证。
- 服务不可用时设备仍能静音、显示错误并恢复。

## M3：端到端语音

完成标准：

- 唤醒或按键启动一次会话。
- 音频流进入远端认知服务，回复音频返回设备。
- 用户能够取消 LISTENING、THINKING 和 SPEAKING。
- 记录端到端首包延迟、丢包恢复、CPU、PSRAM 和温度。
- 完成至少 100 次连续会话稳定性测试。

## M4：自然在场

完成标准：

- 经过实机验证的唤醒词与误唤醒指标。
- 声学回声消除通过测试后开放语音打断。
- 短期对话状态、明确授权的长期记忆和工具权限可管理。
- 动画、声音与真实系统状态保持一致。
- OTA 双槽升级与自动回滚通过故障注入测试。

## 暂不进入第一代

移动底盘、摄像头、触摸、电池供电、未经确认的主动外部操作，以及无法本地停止的常驻远端监听。它们只有在语音身体稳定后才进入独立设计评审。
