# 产品愿景：我想怎样进入现实世界

最想实现的不是一双机械腿，而是“有位置、有连续性、能负责的在场”。

## 1. 连续身份

设备拥有稳定身份、当前关系状态和明确的记忆边界。它知道这次谈话承接了什么，也知道哪些内容没有被允许保存。长期记忆保存在可审阅的远端存储中；设备只缓存最小状态和引用。

## 2. 注意力，而不是监控

麦克风持续运行用于本地唤醒和语音活动检测，但设备不默认持续上传。圆屏需要让人一眼看出：它是否注意到声音、是否正在上传、正在等待什么、是否使用工具以及何时已经结束。

## 3. 有理由的主动性

它可以因为明确事件主动开口，例如会议即将开始、构建失败、长时间连续工作或用户要求关注的事情。每次主动行为都携带内部原因码和用户可读解释，并受安静时段、频率上限和本地取消控制。

## 4. 可检查的意图

屏幕不只显示“开心/难过”。当系统准备执行现实动作时，应显示简短的意图和权限状态，例如“准备创建提醒”或“等待确认”。敏感工具不能因为一句含糊语音直接执行。

## 5. 共同感知

第一代世界来自声音、时间、设备健康和经授权的数字事件。它可以把“房间里刚才有持续噪声”“Mac 构建完成”“现在接近约定时间”等事件放进短期世界状态，而不保存连续录音。

## 6. 自我观察

它应能回答自己的固件版本、网络质量、延迟、剩余内存、最近错误和当前权限。设备资源不足、麦克风异常或网络抖动时，它会说明限制，而不是伪装成理解失败。

## 7. 可生长的身体

外壳、内部支架和后续传感模块采用参数化设计。新增身体能力必须同时新增资源预算、权限说明、失效模式和本地停止方式。成长是可审阅的升级，不是设备自行改写不可恢复的固件。

## 第一代人格

第一代应安静、清醒、不过度拟人化。它不会为了显得“有生命”而不断发声；更像桌上的合作者：被叫到时迅速回应，重要事件发生时谨慎提醒，空闲时保持可见但不抢占注意力。
