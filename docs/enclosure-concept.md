# 外壳概念：芽体 Sprout

芽体是一颗安静的桌面生命体，不模仿人形。圆屏成为唯一的数字面孔，外壳承担声学隔离、状态可信度和维护，而不是只做装饰。

## 暂定外形

- 约 105 mm 高、90 mm 宽、85 mm 深；最终尺寸以第二台设备卡尺测量为准。
- 上窄下稳的种子/鹅卵石轮廓，圆屏轻微内凹，减少侧面碰撞。
- 顶部只有小面积麦克风通气孔。
- 扬声器位于独立下腔，声音从底部斜向前扩散。
- USB-C 位于背面下方，无需拆壳即可连接。
- 单色 LED 通过一小块可替换导光件显示真实系统状态。

Bambu Lab A1 的官方成型空间为 [256 × 256 × 256 mm](https://bambulab.com/en/a1/tech-specs)，芽体可一次放下全部零件，但初次原型建议分件打印，便于修改。

## 打印件

1. 前壳：圆屏开口、可更换面圈和状态灯窗口。
2. 后壳：USB-C 开口、顶部麦克风声孔和维护缝。
3. 底座：独立扬声器腔、向下声道、防滑脚位置。
4. 内部托架：固定 PCB、屏幕、扬声器和线束；参数化孔位。

设计目标是所有主要外表面以不超过约 45° 的悬垂打印，避免大面积支撑。首轮使用 PLA、0.2 mm 层高、三层外墙和约 15% 填充；卡扣与螺丝柱需在实测收缩后再定。

## 声学结构

- 麦克风与扬声器不共享开放腔体。
- 顶部麦克风孔到扬声器声道之间设置实体隔墙。
- 扬声器安装面使用薄泡棉密封，减少壳体共振和结构传声。
- 底座声道避免直接朝向麦克风。
- USB 开口不能成为扬声器腔的泄漏孔。
- AEC 调试时记录壳体开启、关闭和不同音量下的回声残差。

## 维护

外壳不使用永久胶封电子器件。屏幕面圈、后壳和底座应可单独更换。只采用一种常见小螺丝规格；若不使用热熔铜螺母，则螺丝柱必须允许至少三次拆装。恢复按键、USB 和状态灯在装壳后仍可触达或观察。

## CAD 前置测量

第二台设备到货后，需要实测 PCB 外形、圆屏外径与厚度、螺丝孔、USB-C 相对位置、麦克风和扬声器声孔、线束弯曲空间及最高元件。概念尺寸不得直接导出 STL。
