# Self-involving

一个从零设计的实体语音代理项目：让云端智能拥有持续在线、可观察、可中断、可升级的 ESP32-S3 身体。

## 第一代目标

第一代不是移动机器人，也不在设备上运行大模型。它是一台桌面语音身体：

- 本地持续采集声音，但默认只在唤醒或明确会话期间上传语音。
- 通过麦克风和扬声器进行自然语音交流。
- 圆形屏幕和 LED 始终显示设备是在待机、聆听、思考、说话、静音还是故障。
- BOOT 按键承担会话切换，并支持长按进入硬静音/安全模式。
- 通过自定义协议连接远端推理与工具，不依赖 xiaozhi-esp32、旧 bridge 或其云服务。
- 固件支持签名升级、双 OTA 回滚与出厂恢复。

## 硬件目标

- ESP32-S3-WROOM-1-N16R8，16 MB Flash、8 MB Octal PSRAM
- ES8311 音频编解码器，24 kHz I²S 输入/输出
- 1.28 英寸 240 × 240 GC9A01 圆屏
- BOOT 按键 GPIO0、单色 LED GPIO21
- USB Serial/JTAG 和 2.4 GHz Wi-Fi

完整引脚与限制见 [硬件档案](docs/hardware-profile.md)。

## 系统边界

ESP32-S3 是实时身体：音频采集、唤醒、播放、显示、按键、连接与设备安全。远端服务是认知层：语音理解、对话、记忆、工具、权限和语音生成。两层之间只交换有版本的事件、音频帧和状态，不把服务密钥写入设备。

详见 [系统架构](docs/architecture.md)、[隐私与安全](docs/privacy-and-safety.md) 和 [路线图](docs/roadmap.md)。

## 当前阶段

状态：设计阶段，尚未烧录第二台设备。

首个可验证目标：上电完成配网后，说出唤醒词，设备建立一次受控语音会话，播放远端回答，随后可靠回到本地待机；断网、超时或服务错误时仍可通过屏幕、LED 与按键恢复。
